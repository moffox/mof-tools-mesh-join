# MA Mesh Join by Mof

Unity 2022.3 / Modular Avatar 1.18.7 / NDMF 1.14.8向けの非破壊Editor拡張です。
元のScene・Prefab・Mesh・Material・AnimationClip・Controllerは変更せず、NDMFが用意するビルド用アバターで処理します。

## 導入と設定

1. MA・NDMF・VRChat Avatars SDKを導入済みのプロジェクトを使用してください。
2. Package Managerの「Add package from disk」で、このフォルダーの`package.json`を選択します。
3. アバター配下の追加パーツのSkinnedMeshRendererに、`Add Component > MofTools > MA Mesh Join by Mof`を追加します。
4. 結合先、結合距離、処理順、固定削除マスクを設定します。
5. ビルドまたはNDMFの処理済み複製で確認してください。通常の編集用アバターのメッシュを直接置き換える機能ではありません。

初回追加時、同じオブジェクトにある非反転のMA Mesh Cutter 1個とUVマスクフィルター1個を自動移行し、移行したコンポーネントを削除します。Undo可能です。未対応のフィルター、複数Cutter、反転設定は削除しません。後から追加したCutterを自動削除し続ける機能はありません。

`Tools > Mof ツール一覧`には、インストール済みツールとバージョンを表示するウィンドウがあります。前提アセットは不足・古いバージョンの場合だけ表示し、導入済みのものは表示しません。追加方法の案内は各ツールの項目内に表示します。確認専用で、開いてもインストール・設定変更は行いません。

Packagesでは`MofTools > Mesh Join`という構成です。UnityのPackages直下はパッケージ単位で表示されるため、`MofTools`は今回のパッケージの表示名、`Mesh Join`はその中の実フォルダーです。パッケージ識別子・アセンブリ名・スクリプトGUIDは維持しています。

表示と診断メッセージはMA/NDMF共通の言語設定に追従します。日本語と英語に対応し、それ以外は英語になります。MAはUnity Editorの表示言語ではなく、この共通設定を使います。未設定時の初期値はOSの言語です。

削除モードの選択肢はMAと同じ標準Enum表記に合わせ、言語によらず`Delete Black` / `Delete White`と表示します。Inspector内には重複するツール名のタイトルを表示しません。

## 前提アセットの不足

確認対象の前提アセットはModular Avatar 1.18.7以上、NDMF 1.14.8以上です。バージョンの上限は設けません。VRChat SDKは確認対象・必須条件に含めません。

不足・最低バージョン未満を検出した場合、結合機能部分をコンパイル対象から外し、依存のない一覧画面から状態を確認できるようにします。一覧の左端に警告アイコンを表示し、まず「Modular Avatar が導入されていません。」などの具体的なエラー、その後に導入案内を表示します。「必要: >= ...」のような追加行は表示しません。古いバージョンの場合は「Modular Avatar 1.18.7以上を導入してください。」のような文章で案内します。

Unityのビルド前処理と、VRChat SDK Baseがある場合のアバタービルド前処理でもMA・NDMFをチェックして停止します。NDMFがある場合は、MAがなくてもNDMFからの直接処理を開始時にエラーにします。VRChatのリップシンク・まぶたの参照修正はSDK導入時だけ行い、それ以外はNDMFのアバタールートを使用します。この拡張から不足アセットを自動インストールしたり、パッケージを自動更新することはありません。

依存が不足している間は結合コンポーネントの型も読み込まれないため、既存のコンポーネントがMissing Script表示になる場合があります。元のスクリプト・GUID・シリアライズ項目は変更せず、対応する前提アセットを戻すと読み込み対象へ戻ります。

結合先を指定するMA Mesh Cutter、MA Shape Changerの面削除が別の場所に残っている場合も、二重削除を防ぐためビルドをエラーにします。

## 設定の意味

- **結合先**: 同じアバターのSkinnedMeshRenderer。直接参照とアバタールートからの相対パスを保持します。Inspector表示時と階層変更時に参照を補完します。パスが複数に一致する場合はエラーです。
- **結合設定**: 初期状態は閉じた折りたたみ項目です。結合距離・処理順・マテリアルのアニメーションを含みます。
- **結合距離**: ワールド座標の許容距離。初期値`0.00001`。`1e-05`のような指数表記を使わず、通常の小数で表示します。入力はEnterまたはフォーカス移動で確定します。距離外を吸着しません。
- **処理順**: 小さい値から。同じ値はMA処理前のHierarchy順。後側が境界の位置・ウェイト・同名BlendShape初期値とアンカー設定を優先します。
- **マテリアルのアニメーション**: 初期値「上書きしない」は統合元の`material.*`カーブをすべて破棄し、統合先の既存カーブを保持します。「統合先を優先して上書きする」「統合元を優先して上書きする」は統合先Rendererへのパス移行を許可し、両側に同じプロパティがある場合は優先しない側のカーブを全ステート・レイヤーから除去します。片側だけにあるプロパティはどちらの優先設定でも保持します。複数パーツは処理順に適用します。
- **統合先の処理**: 新規コンポーネントでは「なにもしない」が初期値です。「指定された面を削除する」を選択するとマスク設定を表示します。既存の設定済みコンポーネントとCutterから移行した削除設定は保持します。
- **マスク設定**: MA Vertex Filter - By Maskに合わせ、マテリアルスロット選択と参照Materialの読み取り専用表示、マスクテクスチャー、削除モード、選択モード、UV チャンネルを並べています。マスクの完全な白または黒で三角形を削除します。
- 「なにもしない」の場合、すでに開いている統合先の境界を使用して結合します。メッシュ統合自体を無効にする選択肢ではありません。

アンカー・Root Bone・Boundsは、MA Mesh Settingsとボーン統合を処理した後の、最後の追加パーツから採用します。削除するオブジェクト自身を参照する構成では警告し、統合先の一組を保持します。Boundsの自動拡大は行いません。全体を収める値を指定してください。

## 結合・変形

全BlendShapeが0のメッシュ基準形状で、固定削除によって新しくできた切り口と追加側の開口部を照合します。現在のBlendShape値やボーンポーズを頂点へ焼き込みません。シーンのRenderer参照、配置、回転、スケールは使用します。

Blenderでポーズを新しいメッシュ形状として確定して出力した場合、その形状が基準です。ポーズ前の形を復元する機能はありません。本体と追加側の基準形状・バインド情報が対応する必要があります。

UVによる内部頂点分割は位置と辺構造から判定し、属性が同じ結合境界は実際に頂点をまとめます。UV、カラー、接線などが異なる場合は分割を残し、位置・ウェイト・BlendShape変形・法線を揃えます。同位置に別面が重なる多様でない構造や、分割頂点の変形が食い違う構造は安全のため停止します。

UV0～UV7は同番号を保持し、不足チャンネル・成分は0で補完します。UVの再展開、平均化、パッキングは行いません。境界以外の法線を再計算しません。接線はUVごとの方向と反転を保持して境界法線へ合わせます。

同名BlendShapeでも境界以外の各メッシュの変形は保持します。境界の変形は追加側優先、片側にしかない形状はその側を使用します。異なるフレーム重みは和集合にし、区分線形補間して保持します。初期値はRendererの値として保持します。

## アニメーション・削除

MAのAnimator統合・生成アニメーション・ボーン統合後に処理します。

- BlendShapeカーブとマテリアルスロット差し替えを統合先へ移行します。
- `material.*`のカーブは結合設定で上書きを許可した場合に移行します。統合先の他のマテリアルにも作用する可能性があります。競合で除去した側のステートに優先側のアニメーションを追加する処理は行いません。色の各成分など、記録されたプロパティ名ごとに判定します。
- 同じMaterialアセットのスロットをまとめ、差し替えカーブの番号を変換します。
- 追加Rendererの有効/無効と追加GameObject自身のON/OFFカーブだけを除去します。Clipの他カーブ、統合先自身のON/OFF、メニュー、パラメーターは保持します。
- 追加側の確認用メニューは残りますが、除去した表示切替はビルド結果に作用しません。
- 親のON/OFFは統合先へ転送しません。親が追加ボーンも含めて無効化する構成には注意してください。
- VRChatのリップシンク・まぶたのRenderer参照、まぶたのBlendShape番号を更新します。
- 統合元GameObjectの子は親へ移して残します。未対応コンポーネントや削除対象への未対応直接参照がある場合はエラーにします。

異なる元Renderer・元マテリアルスロットの独立したBlendShapeアニメーションやマテリアル差し替えが同じ出力プロパティへ集約される場合はエラーです。`material.*`だけは明示した優先設定で競合を解決します。同じ元プロパティを複数のステートで操作する既存構成は保持します。異なるレイヤー・ステートの排他性を自動証明する機能はありません。

## 現在の対応範囲

- 三角形のSkinnedMeshRenderer、ボーン付きメッシュを対象とします。Cloth、ボーンなしメッシュ、統合元をさらに別の統合先とする連鎖構成には対応しません。
- Renderer自身を片側だけボーン配下に置く構成は、ポーズで結合基準座標が変わるためエラーにします。今回のアバターのようにRendererをアバター直下へ置き、bonesで変形する構成に対応します。
- Renderer全体に作用する`material.*`プロパティアニメーションは、初期設定では統合元側を破棄して統合先側を保持します。上書きを許可すると移行しますが、元のマテリアルスロットだけに作用範囲を限定する機能はありません。統合先に保持した既存アニメーションも統合後の他のマテリアルに作用する可能性があります。マテリアルアセット差し替えはスロット番号を変換して移行します。
- 統合元のTransformアニメーション、表示切替以外の未対応Rendererプロパティは移行せずエラーにします。
- 任意のスクリプト内の文字列パス、外部アセットや非シリアライズ参照までは検出できません。
- 同位置の別面や非多様体構造の自動修復、穴埋め、頂点数が異なる切り口のリトポロジーは行いません。
- 同位置の頂点を含む退化面が結合境界の外にある場合、その面を境界判定から除外し、面・頂点属性・BlendShapeは保持します。結合する境界に接する場合は、安全に対応を確定できないためエラーにします。
- 他のNDMF拡張がこの処理より後でアニメーションやRendererを変更する場合、その変更との整合は別途検証が必要です。

検証実績は`VALIDATION.md`を参照してください。

## アイコン

コンポーネントアイコンは、指定によりMAのRuntimeスクリプトアイコンをコピーした仮アイコンです。元とは別GUIDで管理しています。後で`Mesh Join/Editor/Icons/MeshJoin.png`を差し替えられます。権利表記は`THIRD_PARTY_NOTICES.md`に収録しています。

シーン上のアイコンはプロジェクトごとの初回設定で非表示にします。Inspectorなどのコンポーネントアイコンは維持します。後からUnityのGizmosメニューで手動で表示を有効にした場合、その選択を再読み込み時に上書きしません。
